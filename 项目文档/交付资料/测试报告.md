## 复现方式

在项目根目录执行。浏览器检查需要先启动前后端服务，`tools/Start-Demo.ps1` 默认启动生产预览。

```powershell
node --test tools/tree-layout.test.mjs
python tools/verify_api.py --report test-results/api-h2.json --demo-system-checks
python tools/verify_mysql.py
node tools/verify_browser.mjs
python tools/verify_delivery.py
```

浏览器验收默认访问 `http://127.0.0.1:5175`，也可用 `TEST_BASE_URL` 指向其他生产预览地址。测试脚本的非零退出码表示检查失败，JSON结果中保留失败项。截图由测试脚本在实际页面操作后生成。`verify_delivery.py` 在打包后执行，核对压缩包与验收记录的一致性。

## 验证中修正的问题

- 为生成主键明确指定ID列，兼容H2返回多列生成值的情况。
- 为递归查询明确指定CTE列名，兼容演示数据库。
- 按实际可见人物过滤关系两端，避免通过关系姓名读取私密人物。
- 过滤分页条件应用于总数和记录查询，避免只筛选当前页。
- 使用家族事务锁防止并发反向关系产生闭环。
- 审核前比对人物快照，避免旧申请覆盖已修改资料。
- 为审核确认框设置中文按钮，并对移动端自动折叠侧栏。
- 为两个PowerShell脚本补充UTF-8 BOM，避免Windows PowerShell 5.1按本地代码页解析中文时报语法错误。
- 统一前端视觉主题，替换侧栏印章标识，移除登录页遗留的心理健康文案与不匹配的AI配图。
- 无头Chrome在本机被系统连续关闭时，改用本机Edge完成最终21项浏览器验收。
