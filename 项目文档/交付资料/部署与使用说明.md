# 宗脉电子族谱部署与使用说明

本说明覆盖独立演示环境和 MySQL 本地部署，适用于开发检查、课程展示与源码交接。项目实际认证方式为 Session 与 CSRF，前后端通过同源 `/api` 请求连接。

## 环境要求

| 组件 | 要求 |
| --- | --- |
| Java | JDK 17 |
| Maven | 3.9或更新版本 |
| Node.js | 22.12以上，或24系列 |
| MySQL | 8.0以上，实际隔离验收使用8.4.9 |
| 浏览器 | 当前版本 Chrome 或 Edge |
| Python | 3.10以上，仅自动化接口验收与打包工具需要 |

## 独立演示环境

在项目根目录安装并构建。

```powershell
cd frontend
npm ci
npm run build
cd ../backend
mvn package
cd ..
.\tools\Start-Demo.ps1
```

前端地址为 `http://127.0.0.1:5175/auth/login`，后端为 `http://127.0.0.1:9080`。启动脚本把运行日志写入 `test-results`，并输出新启动的进程编号。结束演示时，可按这些编号关闭对应进程。若端口已经有服务，脚本使用该端口上的现有服务，启动前应确认服务属于本项目。

默认启动方式为已经验收的生产预览：脚本用 `vite preview` 托管 `frontend/dist`，与21项浏览器操作验收使用同一页面。需要开发热更新时，关闭已有前端进程后运行 `tools/Start-Demo.ps1 -Development`，该开关会改用 Vite 开发服务器。

演示账号为 `demo_admin`、`demo_member`、`demo_outsider`，初始密码均为 `Demo123!`。首次启动前可设置 `DEMO_PASSWORD`。管理员账号可维护五代演示家族，普通成员可查看资料并申请修改，无关联账号只能看到自己的空家族列表。

H2文件位于 `backend/data/demo.mv.db`。应用关闭后可以复制该文件保存演示进度。重新启动沿用已有数据。浏览器会话保存在后端内存中，后端重启后重新登录。

## MySQL 初始化

用 MySQL 管理账号打开命令行，按实际项目目录执行。

```sql
SOURCE C:/项目目录/backend/src/main/resources/db/schema.sql;
USE family_tree;
SOURCE C:/项目目录/backend/src/main/resources/db/extensions.sql;
```

随后创建应用账号。下例中的密码需要替换为自行设置的值。

```sql
CREATE USER 'family_app'@'localhost' IDENTIFIED BY '替换为自行设置的数据库密码';
GRANT ALL PRIVILEGES ON family_tree.* TO 'family_app'@'localhost';
```

已有 `family_app` 账号时，按实际授权情况维护账号。系统启动时检查缺失字段并补充家训、公开状态、字辈和籍贯等字段，首次升级需要该数据库的 `CREATE`、`ALTER` 权限。建表脚本使用 `CREATE TABLE IF NOT EXISTS`，旧表字段通过 `SchemaUpgrade` 补充。

## 启动 MySQL 版本

在项目根目录执行。

```powershell
.\tools\Start-MySQL.ps1
```

脚本在需要时提示输入数据库密码。密码通过环境变量传入Java进程。后端默认8080端口，数据库默认 `localhost:3306/family_tree`。修改连接信息可以设置 Spring 标准环境变量。

```powershell
$env:SPRING_DATASOURCE_URL='jdbc:mysql://数据库地址:3306/family_tree?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai&characterEncoding=utf8'
$env:SPRING_DATASOURCE_USERNAME='family_app'
$env:SYSTEM_ADMINS='已预先创建的可信管理账号'
.\tools\Start-MySQL.ps1
```

系统管理员用户名由 `SYSTEM_ADMINS` 配置，多个账号使用逗号分隔。应先创建并核实这些账号，再配置管理员名单。家族管理员通过每个家族的账号关联表独立授权。

如果Maven中央仓库连接失败，可以在backend目录使用项目附带的镜像设置执行 `mvn -s tools/maven-settings.xml package`。

另开前端终端执行。

```powershell
cd frontend
npm run dev
```

正式静态部署使用 `npm run build` 生成的 `frontend/dist`。Web服务器需要把 `/api` 转发至后端，并将其他前端路由回退到 `index.html`。使用HTTPS部署时启用安全会话Cookie。

```powershell
$env:SERVER_SERVLET_SESSION_COOKIE_SECURE='true'
```

## 导入五代演示 SQL

先通过网页注册一个账号，随后用有建表和例程权限的管理账号打开 `family_tree`。把 `demo-data.sql` 末尾 `CALL` 中的 `demo_admin` 替换为实际注册用户名，再执行该脚本。脚本在一个事务中创建新家族、36个人物、57条关系和2件家族事件，并为指定账号关联管理员角色。

```sql
USE family_tree;
SOURCE C:/项目目录/backend/src/main/resources/db/demo-data.sql;
```

脚本使用自动生成的主键，适用于已有其他家族的数据环境。重复成功执行会创建新的演示家族。脚本成功后返回新家族编号。

网页“创建五代演示家族”按钮提供同等的数据准备入口，适用于当前登录账号。

## 页面操作

1. 登录后从家族总览选择家族。可创建家族并维护姓氏、堂号、祖籍、家训和简介。
2. 成员档案页支持新增、编辑、删除、姓名和世代及出生年份筛选。日期允许留空，逝世日期须晚于或等于出生日期。
3. 维护关系时分别选择亲子、配偶或收养类型，并用编号区分同名成员。
4. 图谱页支持缩放、拖动、搜索定位、点击卡片、查看亲属、折叠后代和指定人物展开。
5. 相册页上传PNG、JPEG、GIF或PDF，单文件最大8MB，可关联人物或事件。人物编辑窗口可以选择相册图片作为头像。
6. 普通成员通过“申请修改”或“申请添加关系”提交申请，管理员在审核页处理。资料已变化的旧申请需要驳回后重新提交。
7. 账号与角色页按已注册用户名关联账号，支持管理员和普通成员角色。系统会保留至少一位启用的家族管理员。
8. 家族简介公开开关只公开名称、姓氏和简介。游客通过 `/public` 浏览公开内容。人物的 `PUBLIC` 标记仍受家族访问权限约束。

## 备份与恢复

管理员可从设置页导出CSV或JSON。CSV用于表格处理，JSON保存家族资料、人物、关系、事件和档案文件的Base64内容。JSON导出供资料留存和数据交换使用，当前恢复入口为MySQL数据库恢复。

完整备份可在MySQL客户端目录执行以下命令，并按提示输入管理账号密码。

```powershell
mysqldump -u root -p --single-transaction --routines --triggers --hex-blob family_tree --result-file=family-tree-backup.sql
```

恢复时在MySQL交互客户端中执行。

```sql
CREATE DATABASE IF NOT EXISTS family_tree CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
USE family_tree;
SOURCE C:/实际备份目录/family-tree-backup.sql;
```

恢复前应确认目标数据库和备份来源。现有本机MySQL原数据的升级与恢复需使用实际数据库密码操作。

## 核对交付压缩包

交付压缩包位于 `交付包/宗脉电子族谱-源码与演示包.zip`。在项目根目录执行以下命令，脚本会逐一核对清单路径、文件大小与SHA-256、必需文件、禁用内容和三份验收记录。

```powershell
python tools/verify_delivery.py
```

核对失败时脚本以非零状态退出并列出具体条目。压缩包不包含本地数据库、`node_modules`、测试日志或临时MySQL数据目录。

## 排错

| 现象 | 检查方式 |
| --- | --- |
| 登录接口502 | 查看后端端口、进程和Vite代理目标 |
| 数据库连接失败 | 查看数据库服务、数据库账号及 `DB_PASSWORD` |
| 写请求403 | 重新登录，核对当前账号的家族角色与CSRF令牌 |
| 修改关系409 | 检查重复关系、亲子环路和关联数据 |
| 人物删除409 | 先处理始祖、亲属关系和人物关联事件或档案 |
| 打包无法重命名JAR | 先停止占用该JAR的后端进程再构建 |
| 开发模式访问图谱时页面重载 | Vite首次优化新依赖后重新进入页面 |

`test-results` 保存验收日志，`项目文档/交付资料` 保存供交付的说明、报告和截图。开发依赖与数据库运行文件在Git忽略规则中排除。
